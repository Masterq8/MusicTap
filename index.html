关于星海共振

项目概念

星海共振是一款网页端互动音画交互作品。每次点击都是一次"星体诞生"——粒子从点击点向外爆发，波纹如超新星扩散，频谱如星云律动。

与 Mikutap 的差异化

  • 新增真实粒子物理系统（速度/阻力/寿命/连线）
  • 新增环形频谱可视化
  • 支持 6 种实时合成音色 + 5 套主题配色
  • 纯 Web Audio API 实时合成，零外部音频资源

操作说明

  • 鼠标点击 / 拖拽：产生音画联动
  • 键盘 QWERTY / ASDF：模拟钢琴演奏
  • Y 轴 → 音高：上方高音、下方低音
  • X 轴 → 声像：左 / 右声道

技术栈与适配

Web Audio API · PIXI.js v6 · jQuery
适配设备：PC 网页端 · Chrome / Edge 最新版
